# ฟีเจอร์ฝั่งโฮสต์ (Host) — SubSub

> เอกสารสรุปว่าโฮสต์ (เจ้าของกลุ่ม) ทำอะไรได้บ้างในแอป และมีอะไรปรับล่าสุด
> โฮสต์ = คนที่สมัครบริการจริง แล้วเปิดกลุ่มให้เพื่อนมาหารค่าสมาชิก

## 1. สร้างกลุ่ม (หน้า Create)
- กรอก: ชื่อบริการ, ราคาเต็มทั้งกลุ่ม, จำนวนสมาชิก (รวมโฮสต์), หมวดหมู่, บัญชีรับเงิน, รอบบิล (รายเดือน/รายปี), วันตัดรอบ
- บัญชีรับเงินแยกเป็น 3 ช่อง: ชื่อธนาคาร / เลขบัญชี (หรือพร้อมเพย์) / ชื่อบัญชี
- ระบบออกรหัสเชิญให้อัตโนมัติ

## 2. แก้ไขกลุ่ม (หน้า Edit)
- แก้ชื่อบริการ / ราคา / จำนวนสมาชิก / หมวดหมู่ / บัญชีรับเงินได้
- ราคาที่แก้ **มีผลรอบบิลถัดไป ไม่ย้อนหลัง** (รอบปัจจุบันยังใช้ราคาเดิม)
- ไม่แตะรหัสเชิญ / รหัสกลุ่ม
- **ไม่มีปุ่ม "ลบสมาชิก"** — ตัดออกเพื่อกันโฮสต์โกง โฮสต์เอาสมาชิกออกเองไม่ได้
  (สมาชิกออกได้เองเท่านั้น หรือระบบตัดออกอัตโนมัติเมื่อค้างชำระเกินกำหนด)

## 3. ดูรายละเอียดกลุ่ม (หน้า Detail)
- เห็นรายชื่อสมาชิกทั้งหมด + สถานะบิลของแต่ละคน (จ่ายแล้ว / รอตรวจ / ค้างชำระ + นับถอยหลัง)
- เห็นรายการ "คำขอเข้า (จองที่นั่งแล้ว)" ของคนที่ขอเข้ากลุ่ม
- สรุปจำนวนคนค้างชำระ

## 4. ตรวจสลิป (อนุมัติ / ปฏิเสธ)
- เปิดดูรูปสลิปจริง + ประวัติการส่ง
- กด **อนุมัติ** → สมาชิกเปลี่ยนเป็น "จ่ายแล้ว" (ถ้าเป็นสลิปแรกเข้า = รับเข้ากลุ่ม)
- กด **ปฏิเสธ** พร้อมระบุเหตุผล → สมาชิกส่งสลิปใหม่ได้ (ใบใหม่เข้าคิวตรวจ ใบเก่าเก็บเป็นประวัติ)
- อนุมัติ/ปฏิเสธอ้างอิง "ใบที่เปิดดูอยู่" เท่านั้น กันกดผิดใบ

## 5. อนุมัติ/ปฏิเสธคำขอเข้ากลุ่ม
- คนขอเข้าจะจองที่นั่งทันที (นับรวมที่นั่งเต็ม) พร้อมแนบสลิปแรกเข้า
- โฮสต์ตรวจสลิปแรกเข้าเพื่ออนุมัติเข้ากลุ่ม หรือปฏิเสธให้ส่งใหม่
- ถ้าที่นั่งเต็มแล้วจะอนุมัติเพิ่มไม่ได้

## 6. แจ้งเตือนสมาชิก
- ปุ่ม 🔔 แจ้งเตือนสมาชิกที่ยังไม่จ่าย / ค้างชำระ ให้รีบชำระ
- แสดงเวลาที่แจ้งเตือนล่าสุด

## 7. ปิดกลุ่ม
- ปิดกลุ่มได้ (ลบแบบซ่อน) — สมาชิกทุกคนหลุดออก แต่ประวัติค่าใช้จ่ายยังอยู่ใน Dashboard ของทุกคน

## 8. รหัสเชิญ
- รูปแบบใหม่: **6 ตัว ตัวอักษร A–Z + เลข 2–9 ผสมกัน ไม่มีขีด** (ตัดตัวที่สับสนง่าย 0/O/1/I)
- **เปลี่ยนทุกต้นรอบบิลอัตโนมัติ** — รหัสเก่าใช้ไม่ได้ทันทีที่ขึ้นรอบใหม่

## 9. ภาพรวม / Dashboard
- โฮสต์เห็นยอดค่าใช้จ่ายรวมเดือน/ปี และป้ายเทียบกับเดือนก่อน (↑/↓ %)

---

## สิ่งที่ปรับล่าสุดฝั่งโฮสต์ (session นี้)
- ตัดปุ่ม "ลบสมาชิก" ออกจากหน้าแก้ไขกลุ่ม (กันโฮสต์โกง) — `removeMember` ไม่มีการเรียกจาก UI แล้ว
- แยกบัญชีธนาคารจากช่องเดียวเป็น 3 ช่อง (ชื่อธนาคาร/เลขบัญชี/ชื่อบัญชี)
- รหัสเชิญรูปแบบใหม่ 6 ตัว + เปลี่ยนทุกต้นรอบบิล
- เครื่องมือ dev (เฉพาะโหมดทดสอบ): ปุ่มจำลอง "สมาชิกส่งสลิปใหม่หลังถูกปฏิเสธ" ในหน้าโฮสต์

> หมายเหตุ: ฟีเจอร์เหล่านี้ใช้แกนร่วมกับฝั่งสมาชิก (billing.ts / db.ts / types.ts)
